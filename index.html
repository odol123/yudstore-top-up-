Berapa lama proses top up di YUDSTORE?

Sebagian besar pesanan diproses otomatis dalam waktu kurang dari 10 detik setelah pembayaran terkonfirmasi. Pada kondisi tertentu, seperti gangguan server game atau maintenance, proses bisa memakan waktu hingga 1×24 jam.

Apakah saya perlu memberikan password akun?

Tidak. Kami hanya membutuhkan User ID, username, atau data publik lain yang diperlukan untuk mengirim item. Jangan pernah memberikan password atau kode OTP kepada siapa pun, termasuk pihak yang mengaku sebagai CS.

Metode pembayaran apa saja yang tersedia?

Kami menerima QRIS, DANA, GoPay, OVO, ShopeePay, Virtual Account BCA dan BNI, serta pembayaran tunai di Alfamart. Pilihan pembayaran lengkap akan muncul saat kamu melanjutkan pesanan.

Bagaimana kalau item belum masuk?

Cek dulu ID pesananmu lewat menu Cek Pesanan. Jika status sudah berhasil tetapi item belum terlihat, coba login ulang ke game. Masih belum ada? Hubungi CS dengan menyertakan ID pesanan dan tangkapan layar.

Apakah data akun saya aman?

Ya. Kami hanya menyimpan data yang diperlukan untuk memproses pesanan. Website ini adalah prototipe, sehingga seluruh transaksi, status pembayaran, dan data pesanan disimpan secara lokal di browser perangkatmu.

Bisakah saya membatalkan pesanan?

Pesanan yang belum dibayar akan kedaluwarsa otomatis setelah 15 menit. Untuk pesanan yang sudah dibayar, pembatalan tidak dapat dilakukan karena item biasanya sudah diproses ke akun tujuan.
